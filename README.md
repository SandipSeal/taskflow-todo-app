# TaskFlow Pro

A modern, fast, and responsive To-Do application built with React, Vite, TypeScript, and Tailwind CSS.

## Features

- **Task Management**: Create, edit, mark complete, and delete tasks.
- **Categorization**: Organize by Work, Personal, Study, Health, Finance, and Other.
- **Priority & Due Dates**: High, Medium, and Low priorities with due date tracking and overdue warnings.
- **Filters & Search**: Fast full-text search, status tabs (All, Active, Completed), and multi-criteria sorting.
- **Dark & Light Mode**: Seamless theme switching with system preference detection.
- **Data Persistence**: Auto-saves locally to browser LocalStorage.
- **Backup & Restore**: Export and Import tasks as JSON.
- **Progress Tracking**: Real-time stats and visual progress bar.

## Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```

## Deployment to Vercel

```bash
npx vercel
```
